The Student Portal is a responsive web application built with HTML5, CSS3, Bootstrap 5, and JavaScript that provides students with a centralized dashboard after logging in. It features a collapsible navigation bar linking to Home, Courses, Resources, and Logout pages, a personalized welcome banner that dynamically displays the student's name using sessionStorage, and a set of resource cards granting quick access to Web Development, Database Systems, and Library materials. The project consists of several files Portal.html (main dashboard), Portal.css (custom styles), registration.html (login page), courses.html, and resources.html and is fully mobile friendly thanks to Bootstrap's grid system and responsive components.

To get started, simply download the project files, open registration.html in a browser, and log in; you will be redirected to the portal where your name appears in the welcome header. For full functionality, it is recommended to serve the files via a local server (such as VS Code's Live Server) so that sessionStorage works correctly. The session logic retrieves the student's name on page load and defaults to "Student" if no session exists, ensuring the portal remains usable even without login data, designed to be simple, clean, and student focused.
